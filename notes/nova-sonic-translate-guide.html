Voice Translation Pipeline

Real-time Spanish → English speech translation so your AI agent hears the caller in English — with optional English → Spanish response back.

Choice 2 · Response Direction
One-way: Spanish In, English Out
Caller speaks Spanish → agent hears English. Agent responds in English (no translation back). Simpler setup.
Simpler
# Flow
Spanish Audio → Transcribe (es)
→ Translate (es→en) → Nova Sonic
→ English Response (no TTS back)
Choice 2 · Response Direction
Two-way: Full Bidirectional Translation
Caller speaks Spanish → agent hears English → agent responds → response translated back → Polly speaks Spanish to caller.
Full UX

Spanish Audio → Transcribe (es)
→ Translate (es→en) → Nova Sonic
→ Translate (en→es) → Polly (es)
→ Spanish Audio back to caller
01 Full Pipeline — Step by Step

Click any step to expand its configuration details.

AWS Connect
1 · Caller Dials In (Spanish)
AWS Connect receives the inbound call. A Contact Flow is triggered. Audio streaming begins via the Connect media pipeline.
# Contact Flow setup
Phone Number: Claim in Connect console
Contact Flow: Set language prompt → Spanish
Invoke Lambda: Set at "Get Customer Input" block
Lex Bot Language: es_US or es_419
Amazon Transcribe
2 · Speech-to-Text (Spanish)
Transcribe Streaming converts Spanish audio to Spanish text in near real-time. Use the streaming API for low latency, or Lex for turn-based.
# Streaming Transcribe config
LanguageCode: "es-US" # or es-ES
MediaSampleRateHertz: 8000 # Connect uses 8kHz
MediaEncoding: "pcm"
EnablePartialResultsStabilization: True
Amazon Translate
3 · Translate Spanish → English
The Spanish transcript is sent to Amazon Translate. English text is returned. This is fast (<50ms) and runs inside the Lambda function.
# boto3 translate call
translate = boto3.client('translate')
result = translate.translate_text(
  Text=spanish_transcript,
  SourceLanguageCode="es",
  TargetLanguageCode="en"
)
english_text = result['TranslatedText']
AWS Lambda
4 · Lambda Orchestrator
Lambda is the central glue. It runs Transcribe → Translate → Nova Sonic in sequence and returns the result to Connect. Runs in <3 seconds end-to-end.
# Lambda handler skeleton
def handler(event, context):
  audio = event['Details']['ContactData']
  es_text = transcribe(audio) # step 2
  en_text = translate(es_text) # step 3
  response = nova_sonic(en_text) # step 5
  return {"response": response}
Amazon Nova Sonic · Bedrock
5 · Agent Processes English Input
Nova Sonic receives clean English text and generates its response. From Nova Sonic's perspective it's a fully English conversation — no Spanish ever reaches it.
# Bedrock converse API
bedrock = boto3.client('bedrock-runtime')
resp = bedrock.converse(
  modelId="amazon.nova-sonic-v1:0",
  messages=[{
    "role": "user",
    "content": [{"text": en_text}]
  }]
)
Amazon Translate · Optional
6 · Translate English Response → Spanish
Optional (bidirectional mode). Translate Nova Sonic's English response back to Spanish before speaking it to the caller.
# Reverse translate
result = translate.translate_text(
  Text=nova_english_response,
  SourceLanguageCode="en",
  TargetLanguageCode="es"
)
spanish_response = result['TranslatedText']
Amazon Polly · Optional
7 · Text-to-Speech in Spanish
Optional. Amazon Polly synthesizes the Spanish text into audio that Connect plays back to the caller. Use voice Lupe (US Spanish) or Conchita (ES Spanish).
# Polly synthesis
polly = boto3.client('polly')
audio = polly.synthesize_speech(
  Text=spanish_response,
  OutputFormat="mp3",
  VoiceId="Lupe", # es-US
  LanguageCode="es-US"
)
02 Implementation Code
Python 3.12 lambda_function.py 
import boto3
import json

# AWS clients
transcribe = boto3.client('transcribe')
translate  = boto3.client('translate')
bedrock    = boto3.client('bedrock-runtime')
polly      = boto3.client('polly')

# ── STEP 2: Spanish audio → Spanish text ────────────────────
def transcribe_spanish(audio_s3_uri: str) -> str:
    """
    For streaming (real-time), use amazon-transcribe-streaming-sdk.
    For turn-based (Contact Flow Lambda), use a pre-recorded S3 URI.
    """
    job_name = f"connect-es-{uuid4()}"
    transcribe.start_transcription_job(
        TranscriptionJobName=job_name,
        Media={"MediaFileUri": audio_s3_uri},
        MediaFormat="wav",
        LanguageCode="es-US",
    )
    # Wait for job (use Step Functions for async in prod)
    while True:
        result = transcribe.get_transcription_job(TranscriptionJobName=job_name)
        status = result["TranscriptionJob"]["TranscriptionJobStatus"]
        if status in ["COMPLETED", "FAILED"]: break
    transcript_uri = result["TranscriptionJob"]["Transcript"]["TranscriptFileUri"]
    return fetch_transcript(transcript_uri)

# ── STEP 3: Spanish text → English text ─────────────────────
def translate_to_english(spanish_text: str) -> str:
    result = translate.translate_text(
        Text=spanish_text,
        SourceLanguageCode="es",
        TargetLanguageCode="en",
    )
    return result["TranslatedText"]

# ── STEP 5: English text → Nova Sonic → English response ─────
def call_nova_sonic(english_text: str, conversation_history: list) -> str:
    messages = conversation_history + [{
        "role": "user",
        "content": [{"text": english_text}]
    }]
    response = bedrock.converse(
        modelId="amazon.nova-sonic-v1:0",
        system=[{"text": "You are a helpful agent. Always respond in English."}],
        messages=messages,
    )
    return response["output"]["message"]["content"][0]["text"]

# ── STEP 6 (optional): English response → Spanish ────────────
def translate_to_spanish(english_text: str) -> str:
    result = translate.translate_text(
        Text=english_text,
        SourceLanguageCode="en",
        TargetLanguageCode="es",
    )
    return result["TranslatedText"]

# ── STEP 7 (optional): Spanish text → Polly audio ───────────
def synthesize_spanish(spanish_text: str) -> bytes:
    response = polly.synthesize_speech(
        Text=spanish_text,
        OutputFormat="mp3",
        VoiceId="Lupe",         # es-US female
        LanguageCode="es-US",
    )
    return response["AudioStream"].read()

# ── MAIN HANDLER ────────────────────────────────────────────
def handler(event, context):
    # Connect passes transcript via Lex or Parameters
    spanish_text = event["Details"]["Parameters"].get("TranscribedText", "")
    history      = load_history(event)  # DynamoDB or session attr

    # Translate to English
    english_text     = translate_to_english(spanish_text)

    # Nova Sonic hears English
    english_response = call_nova_sonic(english_text, history)

    # (Optional) Translate response back to Spanish
    spanish_response = translate_to_spanish(english_response)

    # Return to Connect (will use Polly or SSML to speak)
    return {
        "EnglishResponse": english_response,
        "SpanishResponse": spanish_response,
    }

Block 3: Get Customer Input
  └─ Mode: Amazon Lex
  └─ Lex Bot: YourBot (language: es_US)
  └─ Intent captures: FreeformText slot

  -- OR use "Store Customer Input" block --

  └─ Mode: DTMF / Speech
  └─ Set session attribute:
       TranscribedText = $.Lex.IntentName

  └─ Function ARN: arn:aws:lambda:...:translate-agent
  └─ Send session attributes: True
  └─ Timeout: 8 seconds

Block 5: Play Prompt (SSML)
  └─ Use attribute: $.External.SpanishResponse
  └─ Voice: Lupe / Conchita

  • Enable Nova Sonic in Amazon BedrockBedrock Console → Model Access → Request access to amazon.nova-sonic-v1:0
  • Create Lambda function (Python 3.12+)Attach execution role with Transcribe, Translate, Bedrock, Polly, DynamoDB permissions
  • Claim a phone number in AWS ConnectConnect Console → Phone Numbers → Claim → assign to Contact Flow
  • Create Contact Flow with Spanish voiceSet Lex bot language to es_US, invoke Lambda on each turn
  • Create DynamoDB table for historyTable: ConversationHistory, PK: contactId (String)
