# Video Files for PlayVideo Feature

Place your .mp4 files in this folder. They will be served at `/video/<filename>.mp4`.

Current expected file:
- `namma_flame_future.mp4` — triggered when Un-nah says "Playing Namma Flame Future video"

## File naming rules
- Use only letters, numbers, underscores, and hyphens
- No spaces or special characters
- Keep files as small as possible for quick loading
